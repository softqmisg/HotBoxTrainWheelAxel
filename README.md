# HotBoxTrainWheelAxel
HMI for measuring and logging temperature of wheel Axel of train. 

Using following parameters:

* Board is [FULL -STM32H743IIT6-V6.0](https://kavirelectronic.ir/eshop/stm32-board/1201806--ewb-stm32-nano-full-stm32h743iit6-v60-.html#review)  from kavirelectronic 
* TouchGFX [Deisgner] 4.25,double buffering
* QuadSPI(8MB) for saving Font and images
* LCD 7.0" 40Pin,16Bit,800x480
